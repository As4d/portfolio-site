# Portfolio Website

Welcome to my personal portfolio website repository! This project serves as a digital showcase of my skills, projects, and professional experiences.

## Deployment

I deployed this wesbite using Terraform leveraging AWS S3 and CloudFront. The website is hosted on an S3 bucket configured for static website hosting, and CloudFront is used as a content delivery network (CDN) to ensure fast load times globally.

More details found in this repository: [portfolio-site-iac](https://github.com/As4d/portfolio-site-iac)
